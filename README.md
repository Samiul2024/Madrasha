# Darul Iman Islamiyah

Modern production-grade MERN-based madrasa management platform for Islamic educational institutions in Bangladesh.

---

## 🌙 Project Overview

Darul Iman Islamiyah is a scalable Islamic educational management system designed for:

- Islamic madrasa websites
- Online admission management
- Course management
- Notice publishing
- Donation management
- Admin dashboard operations
- Gallery & event management

The project focuses on:

- Modern Islamic UI/UX
- Mobile-first responsive design
- Clean architecture
- Scalability
- Maintainability
- Production-ready development patterns

---

# 🚀 Tech Stack

## Frontend

- React 19
- Vite
- TailwindCSS v3
- React Router DOM
- Zustand
- Axios
- React Hook Form
- Zod
- Framer Motion
- React Hot Toast

## Planned Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Role-based Access Control
